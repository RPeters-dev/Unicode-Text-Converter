# Unicode Converter

Ein kleiner, browserbasierter Unicode-Text-Converter zum Formatieren von Text mit verschiedenen Unicode-Schriftstilen.

## ✨ Features

- Live-Vorschau während der Eingabe
- Verschiedene Unicode-Schriftstile:
  - Bold
  - Italic
  - Bold Italic
  - Sans Serif
  - Sans Serif Bold
  - Sans Serif Italic
  - Sans Serif Bold Italic
  - Monospace
  - Script
  - Bold Script
  - Fraktur
  - Double Struck
  - Small Caps
  - Circled
  - Squared
  - Underline
  - Double Underline
  - Strike Through
  - Overline
  - Superscript
  - Subscript
- Einzelne Ergebnisse direkt kopieren
- Alle Ergebnisse auf einmal kopieren
- Funktioniert vollständig im Browser
- Keine Installation und kein Backend erforderlich
- Keine externen Bibliotheken notwendig

## 🚀 Verwendung

Einfach die `index.html` im Browser öffnen.

Alternativ kann die Anwendung problemlos über einen beliebigen statischen Webhost bereitgestellt werden, zum Beispiel:

- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel

## 📁 Projektstruktur

```text
unicode-converter/
├── index.html

```

## 🌐 GitHub Pages

Das Projekt eignet sich besonders gut für GitHub Pages.

1. Repository auf GitHub erstellen
2. `index.html` und `README.md` hochladen
3. **Settings → Pages** öffnen
4. Unter **Build and deployment** den Branch `main` und `/ (root)` auswählen
5. Speichern

Danach ist der Unicode Converter direkt über die von GitHub bereitgestellte Pages-URL erreichbar.
